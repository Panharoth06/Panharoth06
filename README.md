## Focus

I build full-stack platforms and then try to break them. Java and Spring Boot on the back end, Next.js on the front, Go when something has to be fast or sit in front of a firewall. Security isn't a side interest — it's why the code is written the way it is.

## Selected work

| Work | Notes |
| :--- | :--- |
| **[raiwall](https://github.com/Panharoth06/raiwall)** | Self-hosted web application firewall and reverse proxy, built as a Caddy module. OWASP CRS inspection, outbound DLP, rate limiting, and an embedded admin dashboard in one binary.<br><sub>Go · Caddy · Vue</sub> |
| **[Document verification](https://github.com/Panharoth06/document-verification-backend)** | Tamper-evident certificate issuance and verification. Playwright renders the document; a SHA-256 digest proves it hasn't changed since.<br><sub>Java 21 · Spring Boot · PostgreSQL · Playwright</sub> |
| **[CodeCompass](https://github.com/Panharoth06/code-compass-backend)** | Algorithm-practice platform with automated judging, packages, badges, and leaderboards. Built by a small team I led.<br><sub>Spring Boot · Next.js · PostgreSQL</sub> |
